# SPEC-000: DeteCam 시스템 전체 사양

- 상태: V0 문서 검증 완료 · V1 6종 공간 시뮬레이션 완료 · 실측 전 (2026-11-25). 실측값 없음.
- 기준 문서: [AGENTS.md](../../AGENTS.md) — 이 스펙과 다르면 AGENTS.md가 맞다.

## 1. 무엇을, 왜

방 안의 여러 전자기기 가운데 숨은 2.4 GHz · 5 GHz Wi-Fi 카메라를 골라내고, 사람이 돌아다니지 않고도 카메라 방향과 의심 구역을 스마트폰 AR로 보여 준다. 숙소 · 화장실 · 목욕탕 · 탈의실의 몰래카메라와 시험장(교실 · 강의실)의 초소형 카메라를 같은 장비로 찾는다.

## 2. 구성 (`SPEC-002+`)

| 부분 | 내용 | 저장소 |
|---|---|---|
| 수신기 | 지름 10 cm(또는 V3 선택 후보 8.5 cm) 고리 위 정품 2.4/5 GHz 듀얼밴드 다이폴 8개(`dz=0`, 높이 ≤18 cm) + 중심 기준 안테나 1개(9번째 가상 소자 겸용), 단일칩 흡수형 `PE42482` SP8T, Intel AX210NGW + 수동 RF 부호 앵커(V2 검증), 라즈베리파이 5 팬리스(`VesperCSI` + Linux 6.12 LTS, 호스트 GPIO 직결), Burst-TDM 제어 무선(UART BLE / 내부 UART ESP32). 1기(2곳 순차) 또는 2기(동시) | receiver |
| 판별 · 추정 | 수동 802.11 L2/PHY 다중 시간축 카메라 판별(시험장 호환, 자극은 비시험장 선택 보조), `\|H_ref\|^2` 가중 켤레곱 평균(딥 페이드 억제), NEC2 보정표, 방 6면 지도 반영 강건 방향 추정(대형 반사체 면은 선택 · 실험), 현장 보정, 2위치 비동기 신뢰도 가중 의심 구역 | ai |
| 앱 | 방 지도(ARCore, 반사체 선택), Burst-TDM 무선 수신기 조종, AR 방향 부채꼴 · 의심 구역 표시 | app |

## 3. 요구사항

| 번호 | 요구사항 | 수용 기준 |
|---|---|---|
| FR-1 | 카메라 판별 (G1) | 실제 기기(2.4 · 5 GHz 각 별도) 기준 재현율 ≥ 95%, 오탐률 ≤ 5% (기기 단위로 나눈 평가) |
| FR-2 | 방향 추정 (G2) | 같은 방(40명 교실 · 금속 칠판 등) · 자리 · 날에 DiffLoc 재현 장비보다 평균 방향 오차가 3° 이상 작고 95% 지점도 작음 (자리 20곳 이상, 미리 정함, 실패율 포함) |
| FR-3 | AR 표시 (G3) | 의심 구역이 실제 카메라를 포함하는 비율 ≥ 90%, 구역 크기를 함께 보고 |
| NFR-1 | 소음 (R1) | 측정 중 움직이는 부품 · 팬 소음 없음 (1 m 0 dBA) |
| NFR-2 | 비용 (R2) | 시연 시스템 부품 값 < 70만 원 (1기 약 25~34만 원, 2기 약 50~62만 원) |
| NFR-3 | 사용 방식 (R3) | 설치 한 번(위치 2곳까지), 측정 중 사람이 돌아다니지 않음 |
| NFR-4 | 제작 (R5) | PCB 외주 · 납땜 없음, 쇼핑몰 부품 조립 |
| NFR-5 | 독립 동작 | 노트북 없이 배터리(5 V/5 A PD) 수신기와 스마트폰만으로 동작 |
| NFR-6 | 크기 · 무선 연결 (R8 · R9) | 1기 ≤ 12 × 12 × 20 cm, 기기 사이는 무선만(Burst-TDM 측정 무간섭), 측정 중 배터리 동작 |

## 4. 범위 ([AGENTS.md](../../AGENTS.md) 1.1절)

- 필수: 2.4 GHz · 5 GHz Wi-Fi로 보내는 카메라(실시간 영상 · 간헐 스냅샷 모두)의 탐지 + 방향 · 위치 추정 + AR 표시
- 확장 기능: LTE · 이동통신 5G · 블루투스로 보내는 카메라는 존재 여부만 판정(위치 없음)
- 범위 밖: 통신하지 않는 카메라(SD 카드에 녹화만 하는 카메라 등)
