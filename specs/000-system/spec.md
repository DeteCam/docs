# SPEC-000: DeteCam 시스템 전체 사양

- 상태: 설계 검증 중 (2026-11-24). 실측값 없음.
- 기준 문서: [AGENTS.md](../../AGENTS.md) — 이 스펙과 다르면 AGENTS.md가 맞다.

## 1. 무엇을, 왜

방 안의 여러 전자기기 가운데 숨은 Wi-Fi 카메라를 골라내고, 사람이 돌아다니지 않고도 카메라 방향과 의심 구역을 스마트폰 AR로 보여 준다. 숙소의 몰래카메라와 시험장의 초소형 카메라를 같은 장비로 찾는다.

## 2. 구성

| 부분 | 내용 | 저장소 |
|---|---|---|
| 수신기 | 지름 약 10 cm 고리 위 막대 안테나 8개 + 기준 안테나 1개, 기성 RF 스위치 모듈, Intel AX210, 소형 호스트. 1~2기 | receiver |
| 판별 · 추정 | 카메라 판별, 위상 기준 맞추기, 간섭 보정, 지도 반영 방향 추정, 현장 보정, 신뢰도 · 의심 구역 | ai |
| 앱 | 방 지도(ARCore), 수신기 조종, AR 표시 | app |

## 3. 요구사항

| 번호 | 요구사항 | 수용 기준 |
|---|---|---|
| FR-1 | 카메라 판별 | 실제 기기 기준 재현율 ≥ 95%, 오탐률 ≤ 5% (기기 단위로 나눈 평가) |
| FR-2 | 방향 추정 | 같은 방 · 자리 · 날에 DiffLoc 재현 장비보다 평균 방향 오차가 3° 이상 작고 95% 지점도 작음 (자리 20곳 이상, 미리 정함) |
| FR-3 | AR 표시 | 의심 구역이 실제 카메라를 포함하는 비율 ≥ 90%, 구역 크기를 함께 보고 |
| NFR-1 | 소음 | 측정 중 움직이는 부품 없음 |
| NFR-2 | 비용 | 시연 시스템 부품 값 < 70만 원 |
| NFR-3 | 사용 방식 | 설치 한 번(위치 2곳까지), 측정 중 사람이 돌아다니지 않음 |
| NFR-4 | 제작 | PCB 외주 없음, 쇼핑몰 부품 조립 |
| NFR-5 | 독립 동작 | 노트북 없이 수신기와 폰만으로 동작 |

## 4. 범위 밖

전파를 내지 않는 카메라, 블루투스 · LTE 기기의 위치(확장 과제).
