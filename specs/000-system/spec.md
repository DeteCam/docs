# SPEC-000: DeteCam 시스템 전체 사양

- 상태: 설계 · 시뮬레이션 단계 (2026-11-26). 실측값 없음.
- 기준 문서: [AGENTS.md](../../AGENTS.md) — 이 스펙과 다르면 AGENTS.md가 맞다. 지금 설계의 자세한 내용은 [현재_방향.md](../../현재_방향.md).

## 1. 무엇을, 왜

방 안의 여러 전자기기 가운데 숨은 Wi-Fi 카메라를 골라내고, 사람이 탐지기를 들고 돌아다니지 않고도 카메라 방향과 의심 구역을 스마트폰 AR로 보여 준다. 숙소 · 화장실 · 탈의실의 몰래카메라와 시험장의 초소형 카메라를 같은 장비로 찾는다.

## 2. 구성

| 부분 | 내용 | 저장소 |
|---|---|---|
| 수신기 (1기) | 지름 12 cm 고리 위 필름 안테나 16개 + 가운데 기준 안테나 1개, SP16T 스위치, Intel AX210(두 체인) + 앵커, Raspberry Pi CM4, 끄덕이는 머리(−20° · 0° · +20°), 보조배터리 | receiver |
| 판별 · 추정 | 카메라 판별, 위상 기준 맞추기, 간섭 보정, 지도 반영 추정, 여러 자리 융합(방향 · 위치), 신뢰도 판정, 측정 안내 | ai |
| 앱 | 방 지도(ARCore), 수신기 조종(블루투스), 측정 안내, AR 표시 | app |

수신기 1기를 벽 · 선반 · 사물함 위 · 교탁 등 여러 자리에 차례로 옮겨 두고 잰다. 자리마다의 결과를 소프트웨어가 합친다.

## 3. 요구사항

| 번호 | 요구사항 | 수용 기준 |
|---|---|---|
| FR-1 | 카메라 판별 (G1) | 실제 기기 기준 재현율 ≥ 95%, 오탐률 ≤ 5% (기기 단위로 나눈 평가, 2.4 · 5 GHz 각각) |
| FR-2 | 방향 추정 (G2) | 같은 방 · 자리 · 날에 DiffLoc 재현 장비보다 평균 방향 오차가 3° 이상 작고 95% 지점도 작음 (자리 20곳 이상, 미리 정함) |
| FR-3 | AR 표시 (G3) | 의심 구역이 실제 카메라를 포함하는 비율 ≥ 90%, 구역 크기를 함께 보고 |
| FR-4 | 위치 추정 (G4) | 시험실 밖: 공간 종류마다 0.5 m 안 ≥ 80%. 시험실: 진짜 책상이 의심 책상 3곳 안 ≥ 80% |
| NFR-1 | 저소음 (R1) | 1 m에서 거슬리는 소리 없음. 재는 동안 모터 정지 · 드라이버 끔 |
| NFR-2 | 비용 (R2) | 시연 시스템 부품 값 < 70만 원 |
| NFR-3 | 사용 방식 (R3) | 수신기 1기를 여러 자리로 옮겨 잼. 재는 동안 사람이 걷거나 기기를 들고 움직이지 않음 |
| NFR-4 | 제작 (R5 · R6) | PCB 외주 없음, 쇼핑몰 부품 조립 |
| NFR-5 | 크기 · 놓는 곳 (R8) | 1기 가로 · 세로 20 cm 내외. 벽 · 선반 · 사물함 위 · 교탁 어디든. 바닥에 세우는 큰 스탠드 없음 |
| NFR-6 | 무선 연결 (R9) | 수신기 · 폰 사이는 무선만, 측정 중 배터리 동작 |
| NFR-7 | 시험장 (R10 · R11) | 좌석 정보를 미리 입력하지 않음. 좌석마다 기기를 두지 않음 |
| NFR-8 | 독립 동작 | 노트북 없이 수신기와 폰만으로 동작 |

## 4. 범위 ([AGENTS.md](../../AGENTS.md) 1.1절)

- 필수: 2.4 GHz · 5 GHz Wi-Fi로 보내는 카메라의 탐지 + 방향 · 위치 추정 + AR 표시
- 확장 기능: LTE · 이동통신 5G · 블루투스로 보내는 카메라는 존재 여부만 판정(위치 없음)
- 범위 밖: 통신하지 않는 카메라(SD 카드에 녹화만 하는 카메라 등)
