# DeteCam — 문서 허브

> 수신기 1기를 벽 · 선반 · 사물함 위에 차례로 옮겨 두고, 여러 전자기기 가운데 숨은 Wi-Fi 카메라만 골라내 방향과 의심 구역을 스마트폰 AR로 보여 주는 시스템
>
> 상태(2026-11-26): **설계와 시뮬레이션 단계다. 부품은 아직 사지 않았고 실측한 성능 숫자는 없다.** 수신기는 지름 12 cm 고리에 안테나 16개를 올린 스위치 고리 1기이고, 정확도는 소프트웨어(여러 자리 지도 합치기, 믿을 만한 측정 가려내기, 자리 더 재기 안내)로 올린다.
