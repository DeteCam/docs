# DeteCam — 문서 허브

> 방 모서리에 둔 손바닥만 한 수신기로, 여러 전자기기 가운데 숨은 Wi-Fi 카메라만 골라내고 방향과 의심 구역을 스마트폰 AR로 보여 주는 시스템
>
> 상태(2026-11-25): 이전 설계(v6)를 내리고 **움직이지 않는 스위치 고리 수신기(`SPEC-002+`)**로 방향을 확정해 V0 문서 검증과 V1 6종 공간 시뮬레이션을 마쳤다. 실측한 성능 숫자는 아직 없으며, 다음 단계는 집 PC용 최소 부품(약 3.5~5만 원) V2 원리 시험이다.
