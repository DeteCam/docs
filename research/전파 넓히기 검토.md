# 전파 넓히기 검토: 부정행위 사슬, LTE·5G, 블루투스

2026-11-18 조사. 패널은 2.4 GHz Wi-Fi 의 방향만 잰다. 시험 부정행위는 **카메라 → 폰 → AI → 이어폰** 의 사슬로 이루어지므로, 카메라를 직접 못 찾아도 사슬의 다른 고리가 내는 전파로 간접적으로 찾을 수 있는지, 돈과 법의 테두리 안에서 무엇이 되는지 정리했다. 실물로 재 본 것은 없다.

## 1. 한눈에

| 물음 | 답 |
|---|---|
| 사슬을 같이 보면 더 정확해지나 | 그렇다. 자리를 맞히는 힘보다 **'이 기기가 정말 부정행위 장비인가'를 가리는 힘**이 커진다. 카메라가 폰 핫스팟에 붙어 있으면 지금 장치로 폰의 자리도 잴 수 있다 (돈 0). 카메라가 사진을 보낸 직후 폰의 LTE·5G 가 솟는 박자를 맞추면 둘을 한 사슬로 묶는다 |
| LTE·5G 를 잡을 수 있나 | 세 층으로 나눠야 한다. ① **있다/없다** (교실 안 휴대폰이 지금 보낸다): 된다. 5~50만 원짜리 SDR 로 휴대폰이 기지국에 올려 보내는 대역의 세기만 잰다. ② **어디**: 교실을 몇 구역으로 나누는 정도는 SDR 두세 대의 세기 비교나 KrakenSDR(100만 원 안팎)로 되지만 자리까지는 어렵다. ③ **누구·무슨 내용**: 안 된다. 장비가 1,000만 원대이고, 내용을 들으면 통신비밀보호법의 감청이다 |
| LTE 가 안 되면 5G 는 | '있다' 는 LTE·5G 모두 된다 (4.1). **5G 만이라도 자리까지** 는 원리상 된다: 3.5 GHz 패널과 위상이 맞는 2채널 SDR 로, 폰이 16번 올리면 계산상 자리를 90% 맞힌다 (4.4). 그러나 5G 로 좁혀도 쉬워지지 않는다. 장비가 150만 원 넘게 들고, LTE 로 보내는 것(SIM 을 넣는 숨은 카메라 대부분, LTE 로 올리는 5G 폰)을 놓친다. 국내 5G 폰은 대부분 LTE 를 함께 쓰고(NSA), 통신 3사는 올해 말까지 단독(SA)으로 바꾸는 중이다 |
| 무엇부터 | ① 소프트웨어: 사진 주기, 짝 자리 (돈 0) → ② 허브에 RTL-SDR 하나 (5~8만 원): 휴대폰 송신 경보와 사슬 박자 → ③ 필요하면 HackRF (50만 원 안팎): 나머지 LTE 대역과 5G |
| 못 하는 것 | 카메라·폰·이어폰을 모두 선으로 잇고 AI 가 폰 안에서 도는 경우 (전파가 없다). 귓속 이어폰의 자기장. 나중에 몰아 올리는 장치 |

## 2. 사슬: 카메라 → 폰 → AI → 이어폰

2026년 11월에 알려진 수법이다.

- 제63회 세무사 시험 수석 합격자는 초소형 카메라로 문제를 찍어 AI 로 보내고 스마트폰으로 답을 확인했다고 자수했다. 카메라와 폰을 무엇으로 이었는지는 밝히지 않았다 ([파이낸셜뉴스](https://www.fnnews.com/news/202611151534055370)).
- 온라인에 퍼진 수법: 셔츠 단추의 카메라가 **5초마다** 시험지를 찍어 폰으로 보내고, AI 가 푼 답을 귓속의 쌀알만 한 이어폰으로 듣는다. 장비는 카메라 5만 원, 이어폰 1만 원, 이어폰에 소리를 보내는 전류 발생기 5만 원 ([보도](https://supple.kr/news/cmwihlqmggor5al9py87k6ox5)). 카메라·이어폰·보조배터리 묶음이 약 6만 원에 팔린다 ([미주중앙일보](https://www.koreadaily.com/article/20261114231414627)).
- TOPIK 부정 응시 조직은 초소형 이어폰을 쓰려고 목 뒤에 송수신기를 붙였다가 감독관에게 들켰다 ([서울신문](https://m.seoul.co.kr/news/2026/07/21/20260721800006)).
- 수능은 휴대전화를 거두고, 전파탐지기는 내년부터 시험장 보급을 검토한다 ([한국경제](https://www.hankyung.com/article/202610292755Y)). 일부 국가시험은 시판 전파탐지기를 사서 쓰지만 AI 안경을 얼마나 가려내는지는 공개되지 않았다 ([시대](https://www.sidae.com/article/2026110512523337520)). 전파를 막는 장비는 전파법상 제약과 통신 장애 우려로 국가시험에 들어오지 못했다 ([매일신문](https://www.imaeil.com/page/view/2026111514585041999)).
- 2005년에도 수능에 전파탐지기를 시범 도입하려다 **교실 밖 휴대전화에도 반응해서** 접었다 ([한국교육신문](https://hangyo.com/mobile/article.html?no=14259)). 세기만 재는 방법의 가장 큰 숙제가 이것이다 (4.1절).

|---|---|---|---|---|
| 카메라 → 폰 | Wi-Fi (폰 핫스팟에 붙거나 카메라가 Wi-Fi 를 열고 폰이 붙음) | 2.4 GHz Wi-Fi, 사진마다 몰아서 | **탐지와 위치** (패널) | - |

| | 선 (USB) | 없음 | 못 함 | - |
| 폰 → AI | LTE·5G 로 서버에 | 휴대폰 송신: LTE 0.8~2.6 GHz, 5G 3.5 GHz | 못 함 | SDR: 세기 (4절) |
| | 폰 안의 AI | 없음 | 못 함 | - |

| | 폰 → 블루투스 → 무선 이어폰 | 블루투스 | 못 함 | 같음 |

## 3. 지금 장치로 하는 것 (소프트웨어, 돈 0)

1. **사진 주기.** 5초마다 찍는 카메라는 5초마다 사진 한 장(수십~수백 KB)을 몰아서 보낸다. 기기마다 보낸 시각의 주기를 봐서 2~10초의 뚜렷한 주기가 있으면 '사진 주기' 증거를 더한다. 영상을 계속 보내는 카메라(꾸준함), 사람이 쓰는 폰(들쭉날쭉)과 다르다. 의심 점수의 '여러 번 몰아서 보냄'을 다듬는 일이다 ([의심 점수](https://github.com/DeteCam/ai/blob/main/docs/의심%20점수.md) 5절 끝).
2. **짝 자리.** 카메라가 폰 핫스팟에 붙어 있으면 폰은 0.1초마다 비콘을 내고 카메라에게 응답을 보낸다. 패널은 폰의 자리도 잰다. 카메라와 폰이 같은 자리를 가리키면 그 응시자일 가능성이 커진다. 카메라가 Wi-Fi 를 열고 폰이 붙는 방식이어도 폰이 Wi-Fi 로 응답하므로 같다.
3. **모으기.** 5초마다 보내면 20초에 네 번 잰다. 네 번 모으면 교실 평균 79% 다 ([사각지대](https://github.com/DeteCam/receiver/blob/main/docs/사각지대.md)).

## 4. LTE·5G: 세 층

### 4.1 있다/없다: 된다 (세기만 잰다)

**원리.** 휴대폰은 기지국으로 올려 보낼 때 그 대역에서 세게 낸다 (LTE 휴대폰의 최대 송신 세기는 23 dBm, 0.2 W 안팎). LTE 는 올림과 내림의 주파수가 따로라서, 올림 대역에서 센 신호는 가까운 휴대폰뿐이다. 내용은 풀지 않고 '그 대역에서 짧게 솟았다'만 본다. 시험장은 휴대전화를 거두므로 교실 안에서 올림 대역이 솟는 것 자체가 증거다. 쉬는 폰은 거의 보내지 않고 사진을 올릴 때 솟으므로, 3절의 사진 주기와 박자를 맞추기 좋다.

**국내 대역.** LTE 는 850 MHz(대역 5, SKT·LGU+), 900 MHz(대역 8, KT), 1.8 GHz(대역 3, SKT·KT), 2.1 GHz(대역 1, 세 회사), 2.6 GHz(대역 7, LGU+)를 쓴다 ([netmanias](https://www.netmanias.com/en/korea-big3-operators/big-3-operators/528/), 2016년 정리라 그 뒤 재배치가 있었을 수 있다). 올림 대역은 3GPP 규격으로 대역 5 가 824~849 MHz, 8 이 880~915 MHz, 3 이 1710~1785 MHz, 1 이 1920~1980 MHz, 7 이 2500~2570 MHz 다. 5G 는 3.42~3.7 GHz 를 세 회사가 나눠 쓰고 (KT 3.5~3.6 GHz, [powertec](https://portal.powertec.com.au/industry-resources/companies/kt)), 같은 주파수를 시간으로 나눠 오르내린다 (TDD).

**5G 는 지금 LTE 와 함께 간다.** 국내 5G 는 KT 만 2021년부터 단독(SA)이고, SKT 와 LGU+ 는 LTE 를 함께 쓰는 방식(NSA)이다. 두 회사는 올해 안에 SA 를 추진하고 있고 ([딜사이트](https://dealsite.co.kr/articles/170850)), 정부는 LTE 주파수 재할당의 조건으로 SA 전환을 걸었다 ([디지털데일리](https://www.ddaily.co.kr/page/view/2026012811505081307)). 그래서 지금은 LTE 올림 대역을 보면 5G 폰도 대부분 보이지만, SA 로 바뀌면 3.5 GHz 를 봐야 한다. 5G TDD 는 기지국 신호도 같은 주파수에 있지만, 교실 안 몇 m 거리의 휴대폰은 바깥 기지국보다 수십 dB 세게 들리므로 '짧게 크게 솟는 것'으로 가린다.

| 장비 | 받는 범위 | 값 (어림) | 되는 것 |
|---|---|---|---|
| RTL-SDR Blog V4 | 24~1766 MHz, 한 번에 2.4 MHz 폭 ([rtl-sdr.com](https://www.rtl-sdr.com/about-rtl-sdr/)) | 약 30~40달러 (국내 판매처 5~8만 원) | LTE 대역 5·8·3 의 올림 세기. 대역 1·7 과 5G 는 못 받는다 |
| HackRF One | 1 MHz~6 GHz, 한 번에 20 MHz 폭 ([설명서](https://hackrf.readthedocs.io/en/latest/hackrf_one.html)) | 정품 약 340달러 ([SparkFun](https://www.sparkfun.com/hackrf-one.html)), 50만 원 안팎 | 모든 LTE 올림 대역과 5G 3.5 GHz. 넓게 훑는 도구(`hackrf_sweep`)가 있다 |
| KrakenSDR | 24~1766 MHz, 위상을 맞춘 5채널 ([KrakenRF](https://www.krakenrf.com/product-page/krakensdr)) | 499달러부터 (안테나·세금·배송까지 100만 원 안팎) | 방향(방위각). LTE 대역 5·8·3 만 |

- 허브(라즈베리파이)에 USB 로 꽂는다. RTL-SDR 은 파이 3B+ 로 넉넉하다. HackRF 로 넓게 훑는 것은 파이 3B+ 의 USB 가 빠듯할 수 있어 실물에서 본다.
- **잘못 울림.** 거두지 않은 감독관의 폰, 복도와 옆 교실의 폰도 잡힌다 (2005년의 실패). 그래서 (가) 세기 문턱을 교실 안 거리로 잡고, (나) SDR 을 두 곳에 두어 교실 안이면 두 곳 모두 세게 들리는 것을 보고, (다) Wi-Fi 쪽 의심 기기의 박자와 맞을 때만 크게 친다. 감독관 폰은 비행기 모드로 두거나 자리를 알려 둔다.

### 4.2 어디: 구역까지

| 방법 | 돈 | 얻는 것 | 한계 |
|---|---|---|---|
| 박자로 묶기 | 0 (4.1 의 SDR 하나) | 자리는 패널이 잰 카메라 자리를 쓰고, LTE 는 '같은 사슬인가'만 판단한다 | 카메라가 Wi-Fi 가 아니면 자리가 없다 |
| 세기 비교 (SDR 두세 대를 벽에) | 대당 5~8만 원 + 파이 | 앞/뒤, 창/복도 같은 구역 | 교실 안의 세기만으로는 사람과 책상 때문에 크게 틀린다. Wi-Fi 로 계산해 보니 세기만 재는 수신기 20개로도 가슴·안경 카메라의 자리를 28~39% 만 맞혔다 ([사전 검증](https://github.com/DeteCam/receiver/blob/main/docs/사전%20검증.md)) |
| 방향 (KrakenSDR) | 100만 원 안팎 | 방위각 하나. 패널 방향과 엇갈리면 자리 | 지금 예산(54만 원) 밖. LTE 대역 3 까지만. 교실 반사에서의 정확도는 실물로 봐야 한다 |
| 3.5 GHz 패널 + 2채널 SDR | SDR 150만 원~ + 새 안테나 판 | 5G 의 방향과 자리 | 지금 패널의 방식(기준 안테나와 합친 세기를 네 번)은 휴대폰이 띄엄띄엄, 세기를 바꿔 가며 보내서 맞지 않는다. 위상이 맞는 2채널 SDR 로 기준과 안테나를 같은 올림 조각에서 받으면 된다 (4.4). 계산으로는 Wi-Fi 패널만큼 맞히지만 예산 밖이다 |

### 4.3 누구·무슨 내용: 안 된다

- 휴대폰이 올려 보내는 것을 풀려면 공개 도구 LTESniffer 기준으로 USRP X310(두 수신기 장착)이나 GPS 시계를 단 USRP B210 두 대가 있어야 한다 ([LTESniffer](https://github.com/SysSec-KAIST/LTESniffer)). X310 은 약 9,100달러다 ([소개 글](https://prog.world/the-first-open-source-lte-sniffer-with-full-functionality/)). 5G 는 더 비싸다.
- 통신의 내용을 듣는 것은 감청이다. 통신비밀보호법은 감청을 '전기통신의 음향·문언·부호·영상을 청취·공독하여 그 내용을 지득 또는 채록하는 것'으로 정한다 ([대법원 2022도9877](https://www.scourt.go.kr/sjudge/1667627747073_145547.pdf)). 세기만 재는 것은 내용을 얻지 않는다. 다만 이것은 법률 자문이 아니고, 시험장에서 쓰려면 시행 기관과 지도교수님의 검토를 받는다.
- 가짜 기지국으로 폰을 붙잡는 방법, 전파를 막는 방법은 쓰지 않는다.

### 4.4 5G 만이라도 자리까지 잴 수 있나 (2026-11-18 더함)

**짧게: 원리상 된다. 그러나 5G 로 좁힌다고 쉬워지지 않고, 오히려 놓치는 것이 생긴다.** 자리까지 재려면 LTE 든 5G 든 같은 것(위상이 맞는 2채널 SDR 과 그 대역의 안테나 배열)이 필요하다. 막는 것은 대역이 아니라 그 장비의 값이다.

| 물음 | 답 |
|---|---|
| 어떻게 재나 | 지금 패널과 같은 생각이다. 다만 휴대폰은 우리가 시킬 때 보내지 않고 세기도 조각마다 바뀌므로(전력 제어), 기준과 합친 세기를 네 번 재는 지금 방식은 맞지 않는다 (4.2 의 '3.5 GHz 패널'). 대신 위상이 맞는 2채널 SDR 로 한 채널은 기준 안테나, 다른 채널은 스위치로 3.5 GHz 패치 16개를 차례로 받아 **같은 올림 조각 안의 비**를 쓴다. 사진을 올리는 동안 올림 조각이 1초에 수백 번 오므로 16개를 채우는 데 0.1초 안팎이다 |
| 해 본 사람이 있나 | 있다. 시판 2채널 SDR(USRP B210)과 안테나 둘로 상용 5G 폰(삼성)의 방향을 실내에서 1.5도(RMS, 정면 ±30도)로 잰 2026년 논문이 있다 ([Barrios-Muñoz 외](https://arxiv.org/pdf/2608.00080)). 다만 그 논문은 자기 기지국(srsRAN)을 세워 폰을 거기에 붙였다. 통신사 망을 엿들을 때는 폰의 올림 설정(SRS)을 모르므로 세기와 두 채널의 위상차만 쓴다 |
| 계산 | 계산해 봤다 (receiver 저장소 `sim/rt/place_followup.py` 의 `n16`). 같은 교실에서 Wi-Fi 패널과 같은 자리에 3.5 GHz 패널(패치 16개, 반 파장 간격 42 mm)을 걸고 2채널로 받는다고 두고, 책상 위·가슴·머리 높이의 폰이 사진을 올릴 때를 셌다 (Sionna RT, 3.55 GHz, 폰 1,200대). 폰이 16번 올리면 자리를 정확히 / 옆자리까지 **90 / 99%** (기본 배치), **95 / 99%** (2.35 m 배치), 한 번만 올리면 58~70 / 88~92% 다. Wi-Fi 패널로 카메라를 찾는 것과 거의 같다. **물리로는 막히지 않는다.** 막는 것은 아래의 값과 놓치는 것이다 |
| 무엇이 새로 드나 | 3.5 GHz 패치 판 (지금 판은 2.4 GHz 용), 3.5 GHz 를 지나는 스위치, 2채널 SDR. SDR 만 bladeRF 2.0 micro xA4 약 1,000유로 ([SDR Store](https://www.sdrstore.eu/nuand/)), USRP B210 약 2,330달러 ([DigiKey](https://www.digikey.at/en/product-highlight/d/digilent/ettus-usrp-b210-2-x-2-70-mhz-to-6-ghz-sdr-cognitive-radio)). 싼 Pluto 를 두 채널로 고친 것은 4~5 MHz 넘는 폭에서 두 채널의 위상이 어긋났다는 사용자 보고가 있다. 지금 예산(54만 원)의 세 배가 넘는다 |
| 5G 만 보면 놓치는 것 | ① **LTE 로 보내는 것.** SIM 을 넣는 숨은 카메라로 팔리는 것은 대부분 4G LTE 다 (찾아본 제품들이 그랬다). 5G 레드캡 카메라는 이제 나오기 시작했다 ([Askey CAM2303](https://www.askey.com/products/home-iot/89/)). ② **5G 폰의 LTE 올림.** 지금의 NSA 에서는 통신사가 올림을 LTE 쪽으로 보내도록 정할 수 있고, 5G 올림이 약하면 LTE 로 돌린다 ([telecomhall](https://www.telecomhall.net/t/quick-information-on-5g-nsa-ul-fallback-feature/27625)). 통신 3사는 정부의 주파수 재할당 조건에 따라 올해 말까지 SA 로 바꾸고 있지만 ([뉴스토마토](https://newstomato.com/ReadNews.aspx?no=1311728)), SA 에서도 5G 가 약한 곳에서는 LTE 로 넘어간다 |
| 누구인지 | 여전히 모른다. '이 방향에서 5G 휴대폰이 지금 보낸다' 까지다. 여러 폰이 같은 조각에서 보내면 주파수 칸으로 나눠 본다. 시험장은 휴대전화를 거두므로 교실 안에서 보내는 폰이 있다는 것 자체가 증거다 |
| 권함 | 졸업작품에서는 4.1(있다)과 사진 박자까지만 한다. 자리는 Wi-Fi 패널이 맡는다. 예산이 생기면 2채널 SDR 하나와 안테나 둘로 '5G 방향' 시연을 따로 할 수 있다 |

## 5. 블루투스와 이어폰

- 귓속 이어폰은 자기장으로 소리를 받는다. 그 자기장을 목걸이나 '전류 발생기'가 만들고, 그것이 폰과 블루투스로 이어지는 경우가 많다. 전파로 잡을 수 있는 고리는 그 블루투스뿐이다.
- 블루투스 클래식은 채널을 빠르게 뛰어다녀 Wi-Fi 칩으로는 엿들을 수 없다. ESP32-C5 는 블루투스 저전력(BLE)만 된다.
- **Ubertooth One** (100달러대)은 지나가는 블루투스 클래식 패킷에서 기기 주소의 일부(LAP)를 뽑아 '근처에 블루투스 연결이 있다'를 알린다 ([Great Scott Gadgets](https://greatscottgadgets.com/2012/10-17-discovering-bluetooth-devices), [Kismet](https://kismetwireless.net/docs/readme/datasources/bluetooth-ubertooth/)). 위치는 모른다. 시험장에서는 블루투스 이어폰도 반입 금지라 '있다'만으로 감독관을 부를 수 있다.
- 자기장 자체는 수십 cm 안에서만 잡혀 손에 든 탐지기의 몫이다. TOPIK 사건도 감독관이 눈으로 송수신기를 찾았다.

## 6. 권하는 순서

| 단계 | 무엇 | 돈 | 얻는 것 |
|---|---|---|---|
| 0 | 사진 주기, 짝 자리, 사슬 점수 (소프트웨어) | 0 | 의심이 맞는지 더 확실해지고, 사람을 좁힌다 |
| 1 | RTL-SDR V4 + 안테나를 허브에 | 5~8만 원 | LTE 대역 5·8·3 에서 휴대폰이 보내면 경보. 사진 주기와 박자 맞추기 |
| 2 | HackRF One | 50만 원 안팎 | LTE 대역 1·7 과 5G 3.5 GHz |
| 3 | SDR 한두 대 더 | 대당 5~8만 원 | 구역 (앞/뒤, 창/복도), 교실 밖 폰 거르기 |
| - | KrakenSDR, 3.5 GHz 패널 + 2채널 SDR, 내용 풀기 | 100만 원~ / 150만 원~ / 고가·불법 | 졸업작품 범위 밖 (5G 의 자리는 4.4) |

MVP 는 지금처럼 Wi-Fi 로 두고, 관문 5 를 통과한 뒤 0 단계와 1 단계만 더하는 것을 권한다. 1 단계는 6만 원 안팎으로 '휴대폰이 교실 안에서 보낸다'는 증거 하나를 더하는 일이고, 2005년처럼 잘못 울리는지는 실험으로 먼저 본다.

## 7. 실물에서 볼 것

1. 교실 안 폰 한 대가 사진을 올릴 때 RTL-SDR 로 LTE 대역 3 의 올림 세기가 얼마나 솟는지, 복도·옆 교실의 폰과 가를 수 있는지.
2. 단추 카메라 → 폰 핫스팟 → 폰의 LTE 올림까지의 시간 차이 (사진을 받은 뒤 몇 초 안에 올리나).
3. 사진 주기 증거가 정상 앱(메신저 자동 백업 등)을 얼마나 잘못 울리는지 (의심 점수 S5).
4. HackRF 를 파이 3B+ 에서 넓게 훑을 수 있는지.
