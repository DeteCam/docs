# DeteCam 6.0 (`Nano-2 AI`) 종합설계 요약 계획서

1. **목표**: 코트 주머니에 들어가는 **9.6 cm 포켓 벽면 수신기 단 2기(100% 신품 34.6만 원)** + **4대 PyTorch Physics-Informed AI 엔진**으로 숙소·화장실·목욕탕·탈의실·피팅룸·교실·강당 등 다양한 공간에서 불법 Wi-Fi 카메라를 15초 내 설치·정밀 탐지.
2. **하드웨어 개발 (`DeteCam/receiver`)**: `84×84 mm` 4층 RF PCB (`12+1` SMD + `PE42442×4` + `AD8317` + 온보드 `RP2040`) + `NanoPi R5C` (0.8T NPU) + `Intel AX210NGW` + `Bambu X1C` 2판(8시간, 250 g, 서포트 0%) 출력 하우징.
3. **SW/AI 개발 (`DeteCam/ai`)**: `ReconCovNet-v4` (미학습 P90 `-16.8%/-11.1%`), `CamGuard-Net` + 5초 `CamLoPA` (`F1 98.88%`), Bayesian `MA-PINN` 가상 거울 앵커 + `ΔP_12`, `AR-OPA-2` + `RAPS 90%`.
4. **모바일 앱 (`DeteCam/app`)**: 5초 AR 스캔 → 2기 벽면 위치·15° 클릭 각도 안내 → 3초 `Auto-Verify` → 가상 거울 광선 및 `RAPS 90%` AR 표시 + 선택적 0원 보행 정밀 모드.
5. **실측 파일럿 로드맵**: (1단계) 턴테이블 1회 회전으로 `Nano-12` 실측 결합행렬 `C_hat` 획득 → (2단계) 소형 원룸/화장실 2기 실측 미세조정(Fine-tuning) → (3단계) 40석 교실·L자 복도 종합 시연.
