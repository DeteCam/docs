## 프로젝트 소개

Wi-Fi 로 사진·영상을 내보내는 초소형 카메라를 찾아내고, 그 위치(좌석)까지 알려 주는 시스템입니다.

- 수신기가 2.4·5 GHz Wi-Fi 를 분석해 의심 기기를 고르고, 안테나 16개 패널로 전파가 온 방향을 측정함
- 교실은 벽에 건 패널 둘로 사진·영상을 보낼 때마다 재서 쌓고, 숙소 방은 패널 하나를 돌려 찾아 AR 로 표시함
- 직접 만든 두 대역(2.4·5 GHz) 판으로 두 대역 카메라 모두 좌석까지 찾음. 휴대폰(LTE·5G) 송신과 블루투스 기기의 존재 알림은 확장 과제로 둠
- 부품을 싼 순서로 사며 단계별로 검증(관문 1~5, 약 83만 원)하고, 안 되면 받는 쪽만 바꾸는 대안(AX210)과 2.4 GHz 판(CoreHW)을 준비함

## 프로젝트 개요

**1. 주제선정 배경**

- 숙박업소·화장실의 불법촬영과, 시험지를 찍어 외부(AI)로 보내는 초소형 카메라 부정행위가 늘고 있음
- 와이파이 차단은 폰 핫스팟·LTE 로 우회되고 재밍은 불법이며, 기존 탐지기는 전파의 유무만 알려 줌
- 카메라는 어느 망에 붙든 사진·영상을 보낼 때마다 Wi-Fi 전파를 내므로, 끊지 않고 위치까지 찾아야 함

**2. 주제 해결 방안**

- 주변 Wi-Fi 를 수집해 사진·영상을 올리는 기기를 자리·핫스팟 짝·전송 박자로 가려 "의심 점수"로 판별
  - 암호화된 내용은 보지 않음. 빈 프레임에 대한 응답(ACK)을 받아 카메라가 쉬는 동안에도 측정
- 안테나 16개 배열(패널)에서 안테나별 신호의 위상 차이를 구해 전파가 온 방향(방위·고도)을 추정
  - 수신 체인 하나인 저가 보드에서 기준 안테나와의 간섭(위상 4단계)으로 위상을 복원, 모터 없이 0.3초에 측정
  - 전파 계산으로 고른 벽 두 곳의 패널 결과를 사진마다 누적하여 좌석을 추정, 의심 좌석 3곳을 AR 로 표시

**3. 연구 및 개발 목표**

Wi-Fi 송출형 카메라(사진·실시간 영상, 핫스팟·숨긴 망 포함)를 30초 안에 탐지하고(탐지율 90% 이상), 40석 교실에서 사진 4장이면 의심 좌석 3곳 안에 90% 이상·16장이면 95% 이상(정확한 좌석도 함께 측정), 숙소 방에서 두세 곳을 재어 0.5 m 이내(가운데값)로 위치를 추정하여 스마트폰 AR 화면에 표시한다. 2.4·5 GHz 카메라 모두 같은 기준이다. 휴대폰 송신 경보와 블루투스 기기 알림은 확장 과제로 둔다.

**4. 연구 및 개발 내용**

SW

- 탐지 : 2.4·5 GHz 패킷 수집, 기기별 통신 특징(사진 박자·영상 송출·핫스팟 짝) 추출, 의심 점수 계산
- CSI 수집 : ESP32-C5 로 ACK 응답을 유도하고 안테나·위상 단계를 전환하며 수집, 위상 복원 및 보정
- 방향·위치 추정 : 안테나 16개로 도래 방향 계산, 두 패널·여러 전송의 점수 누적, 의심 좌석 3곳 제시
- 사전 검증 : 부품을 싼 순서로 사며 관문 1~5 확인, 안 되면 받는 쪽만 수신 체인 둘(AX210)로 교체
- 두 대역 위상 보정 : 2.4·5 GHz 여러 채널을 묶어 위상 단계를 재고, 보정 전의 대역은 위치를 막아 틀린 자리를 내지 않음
- 수신기 제어 : 안테나·위상 스위치 제어, HTTP API 서버, 노트북 없이 단독 동작(임베디드 리눅스)
- 스마트폰 앱 : 수신기 원격 조종, ARCore 기반 의심 좌석·위치 표시(녹화하지 않음), 근접 확인
- 검증·학습 : 전파 시뮬레이션(Sionna RT, 패널 자리 122곳 비교)과 실측으로 성능 평가, 판별 모델

HW

- 패널 2개(두 대역 필름 안테나 16개 + 6 GHz RF 스위치 + 반사판 + ESP32-C5) + 허브(라즈베리파이 3B+ + 동글)
- 3D 프린터로 출력한 패널·허브 케이스, 자석·흡착 걸이와 경첩으로 벽면 거치, 배터리 전원, 무소음

**5. 결과물 내역**

프로토타입(데모). Software: 수신기 펌웨어, Android AR 앱, 분석 모델. Hardware: 패널 수신기 1벌.

**6. 개발환경**

- 개발언어 : Python, Kotlin, C / 프레임워크 : Jetpack Compose, ARCore, PyTorch
- 주요 라이브러리 : ESP-IDF(esp-csi), NumPy/SciPy, Sionna RT / 개발방법론 : 스펙 주도 개발(SDD)
- 플랫폼 : Raspberry Pi OS(Linux), Android, ESP32 / 형상관리 : Git / GitHub
